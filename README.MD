# User Management & Authentication API

A simple, beginner-friendly backend built with **FastAPI** and **PostgreSQL**.
Covers user registration, JWT login, protected CRUD routes, pagination, and
basic caching — kept deliberately minimal, no extra layers or complexity.

## Tech Stack
- Python + FastAPI
- PostgreSQL (works with pgAdmin)
- SQLAlchemy (ORM)
- JWT (python-jose) for authentication
- Passlib (bcrypt) for password hashing

## Setup

### 1. Create the PostgreSQL database
Open **pgAdmin**, create a new database, e.g. `user_management_db`.
(No need to create tables manually — FastAPI creates them on first run.)

### 2. Configure environment variables
Copy `.env.example` to `.env` and fill in your own values:
```
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/user_management_db
SECRET_KEY=change_this_to_a_long_random_secret_key
ACCESS_TOKEN_EXPIRE_MINUTES=60
```

### 3. Install dependencies
```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 4. Run the server
```bash
uvicorn app.main:app --reload
```
API will be running at: `http://127.0.0.1:8000`
Interactive docs (auto-generated by FastAPI): `http://127.0.0.1:8000/docs`

## API Endpoints

| Method | Endpoint            | Auth Required | Description                  |
|--------|----------------------|:--------------:|-------------------------------|
| POST   | `/auth/register`     | No             | Create a new user              |
| POST   | `/auth/login`        | No             | Login, returns JWT token       |
| GET    | `/users?page=&limit=`| Yes            | List users (paginated, cached) |
| GET    | `/users/{id}`        | Yes            | Get one user                    |
| PUT    | `/users/{id}`        | Yes            | Update own profile              |
| DELETE | `/users/{id}`        | Yes            | Delete own account               |

For protected routes, send the JWT in the header:
```
Authorization: Bearer <access_token>
```

## Testing with Postman
Import `postman_collection.json` into Postman. It includes ready-made
requests for register, login, list, get, update, and delete — with
`{{base_url}}`, `{{token}}`, and `{{user_id}}` variables you can fill in
after login.

## Notes on Design Choices
- **Caching**: a small in-memory TTL cache (30s) speeds up repeated calls to
  `GET /users`. It's intentionally simple — no Redis — and is cleared
  automatically whenever a user is updated or deleted.
- **Pagination**: `GET /users` accepts `page` and `limit` query params.
- **Security**: passwords are hashed with bcrypt, never stored in plain text.
  JWT tokens expire after the configured number of minutes.
